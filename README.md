# 软件开发学习项目合集（dev-learning-projects）

> ⚠️ **声明：本仓库仅供软件开发学习与源码参考。请勿将其直接或稍作修改后作为课程作业、课程设计或毕业设计提交**，这属于学术不端，后果自负。建议阅读代码、理解思路后自己独立实现。

## 选题调研（简要）
整理国内（CSDN、掘金、技术栈等 2026 届选题汇总）与国外（GitHub 课程项目、capstone 常见题目）的软件类热门方向，出现频率最高的三类是：
1. **信息管理系统**（图书、宿舍、医院、校园二手等）——练习增删改查、角色权限、业务状态流转；
2. **小程序 / 移动端预约类**（图书馆座位、场馆、挂号）——练习移动端交互、并发冲突校验、签到与信用；
3. **推荐系统 + 数据可视化**（电影、图书、招聘、电商）——练习协同过滤算法、离线评估、图表展示。

因此本仓库各做一个可运行的参考实现：

| 目录 | 项目 | 端口 |
|---|---|---|
| `01-library-management` | 图书管理系统（管理员/读者双角色） | 8001 |
| `02-seat-booking-mobile` | 图书馆座位预约（移动端 H5，可移植小程序） | 8002 |
| `03-movie-recommender` | 电影推荐与数据可视化 | 8003 |

## 运行
只需 **Python 3.9+**，零第三方依赖（标准库 http.server + sqlite3，前端原生 JS，无需联网）。
```bash
cd 01-library-management && python3 app.py            # 免费版
cd 01-library-management && EDITION=pro python3 app.py # 付费高级版
```
浏览器打开 http://localhost:8001 （8002 / 8003 同理）。首次启动自动建库 `*.db` 并写入演示数据，删除 db 文件即可重置。可用 `PORT` 改端口。

演示账号：
- 图书管理：`admin / admin123`（管理员，可用 `ADMIN_PASSWORD` 环境变量修改初始密码）、`reader / reader123`
- 座位预约：学号 `2026001 / 123456`（新学号首次登录自动注册）
- 电影推荐：`demo / demo123`（新用户名首次登录自动注册）

## 部署说明
- 任意 Linux 服务器：`EDITION=pro PORT=80 nohup python3 app.py &`，或用 systemd 托管；建议前面加 Nginx 反向代理并配置 HTTPS。
- 本项目会话保存在内存、密码 PBKDF2 加盐哈希，适合学习演示；生产使用请改用正式框架（Flask/Django/Spring Boot）、持久化会话和 HTTPS。
- 小程序移植：`02` 的接口与页面结构按小程序习惯设计，`fetch` 换成 `wx.request` / `uni.request`、页面拆成 pages 即可。

## 免费版 / 付费高级版
通过环境变量 `EDITION=pro` 切换；后端对高级接口返回 HTTP 402，前端显示 🔒 提示。

| 项目 | 免费版 | 付费高级版（额外） |
|---|---|---|
| 01 图书管理 | 登录、读者注册接口、图书增删改查与检索、借阅/归还、借阅记录、库存与借阅上限校验 | 逾期罚金自动计算、统计看板（分类占比饼图、热门 TOP5、逾期数）、借阅记录导出 CSV |
| 02 座位预约 | 学号登录、日期/时段/阅览室选择、座位图、预约（冲突与重复校验）、签到、取消、我的预约 | 信用分体系（违约扣分、低于 60 暂停预约）、座位热力图 |
| 03 电影推荐 | 电影浏览与类型筛选、1~5 星评分、热门榜（贝叶斯平均）、基于物品协同过滤 + 推荐理由、基础图表 | User-CF 与 Item-CF 混合推荐、数据大屏（评分分布、类型均分、年份趋势）、留一法 Hit@10 离线评估 |

> 开源代码中的版本开关只是功能划分，不是防破解机制。
